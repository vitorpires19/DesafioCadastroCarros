
# Desafio Cadastro de Carros - EBAC

Projeto desenvolvido como atividade prática do curso
de Desenvolvimento Back-end Java da EBAC.

## Objetivo

Desenvolver um sistema de cadastro de carros utilizando
Programação Orientada a Objetos e vetores em Java.

## Funcionalidades

- Cadastro de até 50 carros
- Validação da quantidade máxima permitida
- Criação de objetos da classe Carro
- Armazenamento de objetos em um vetor
- Exibição dos veículos cadastrados
- Contagem total de carros
- Cálculo da soma dos preços cadastrados

## Estrutura do Projeto

- `Carro.java`: classe responsável pelos atributos
  e métodos dos objetos Carro.
- `CadastroCarros.java`: classe principal responsável
  pelo cadastro e exibição dos resultados.

## Tecnologias Utilizadas

- Java
- IntelliJ IDEA
- Git e GitHub

## Como Executar

1. Abra o projeto no IntelliJ IDEA.
2. Acesse a classe `CadastroCarros.java`.
3. Execute o método `main()`.
4. Informe quantos carros deseja cadastrar.
5. Preencha os dados de cada veículo.
6. Confira o resumo exibido no console.
